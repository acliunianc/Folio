# 工作区

Windows 桌面启动器。每个全屏页面是一个工作区，里面用网格放文件、文件夹、应用和便签。按一次快捷键切到当前工作区，相关资料集中在一屏里。

常驻系统托盘，没有标题栏。显示和隐藏默认用 `F7`。

## 技术选型

界面用网页技术做，系统能力用 Rust 做。包管理用 **pnpm**。

| 层级 | 技术 | 职责 |
| --- | --- | --- |
| 桌面壳 | Tauri 2 | 无边框窗口、托盘菜单、全局快捷键、调用系统接口 |
| 界面 | React 19 + TypeScript | 工作区分页、网格、拖拽、成组、便签 |
| 构建 | Vite | 前端开发服务器和打包 |
| 样式 | Tailwind CSS 4 | 布局和动效 |
| 拖拽 | dnd-kit | 网格项拖拽、成组 |
| 包管理 | pnpm | 安装依赖、运行脚本。不使用 npm 或 yarn |
| 系统能力 | Rust（Tauri commands） | 打开、复制、移动工作区文件夹，创建 `.lnk`，读取系统图标 |

选这套的原因：

- 翻页、预览条、长按编辑、便签缩放都是自定义界面，React 做这些比 WPF / WinUI 快。
- Tauri 使用系统 WebView2，托盘常驻时内存小于 Electron。
- 文件操作和全局热键放在 Rust 里，不放在页面脚本里。

运行要求：Windows 10 及以上，已安装 WebView2（系统 Edge 自带）。需要 Node.js 20+、pnpm 9+、Rust stable。

## 包管理

本仓库只使用 pnpm。

```powershell
corepack enable
corepack prepare pnpm@9 --activate
pnpm install
pnpm tauri dev
pnpm tauri build
```

常用脚本：

| 命令 | 作用 |
| --- | --- |
| `pnpm install` | 安装依赖 |
| `pnpm dev` | 只启动前端 |
| `pnpm tauri dev` | 启动完整桌面应用 |
| `pnpm tauri build` | 打包 Windows 安装程序 |
| `pnpm check` | TypeScript 类型检查 |

## 目录

```text
src/                 React 界面
src-tauri/           Rust 壳、托盘、快捷键、文件命令
需求.md
```

一个工作区就是总文件夹下的一个子文件夹，界面把该文件夹渲染成网格。设置里更改总文件夹位置时，若已有工作区，自动把这些子文件夹移进新文件夹。新位置已有同名文件夹则不覆盖，并取消这次更换。

放入工作区默认是把文件移动进该文件夹。设置里可以改成复制，或改成只建快捷方式，`.md` 和 `.exe` 都按这个设置处理。跨工作区拖拽就是在两个子文件夹之间移动。成组会新建子文件夹并把项目移进去。便签只放在工作区桌面上，不和文件、文件夹或应用成组，也不放进子文件夹。便签保存在对应工作区文件夹内，网格坐标写在该文件夹的 `.layout.json`。

## 第一版范围

- 当前屏幕全屏显示，托盘中打开设置和退出
- `F7` 显示或隐藏，隐藏时进程保持运行
- 多个工作区，拖拽翻页，顶部悬停预览条
- 每个工作区对应总文件夹下的一个子文件夹，放入文件默认移动进该文件夹
- 网格放置文件、文件夹、应用和可缩放便签
- 长按网格项只保持这一次拖动的编辑；长按空白或右键进入的编辑会保留，用来批量操作

## 编辑

编辑有两种，结束方式不一样。

长按空白区域，或在右键菜单里选择「编辑布局」，进入的是批量编辑。这时可以连续拖动多个网格项、删除、放入文件或调整便签。这种编辑会一直留着，直到点底部的「完成」、按 Esc，或在右键菜单里选择「完成编辑」。

长按某个网格项，是为这一次操作进入编辑，松手后该项会马上被拖起来。拖完换位、拖进文件夹、拖到另一个工作区，或拖到屏幕边缘放到外面的窗口，这次编辑就结束。工作区回到普通状态。如果本来就已经在批量编辑里，长按网格项只做这一次拖动，结束后批量编辑还在。
